# שיעורים — תנ״ך 2

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו.

כתובים, מקראות גדולות (ירושלים תרצ״א, מ-HebrewBooks). כל עמוד — PNG שחור-לבן ברוחב 1600.
`thl/` — תהלים · `msl/` — משלי ואיוב · `dan/` — דניאל, עזרא ונחמיה · `dhy/` — דברי הימים · `mgl/` — חמש המגילות (מסוף כרכי החומש של אותה סדרה: שיר השירים, רות, איכה, קהלת, אסתר).
`thlx/` — תהלים, עמודים 205 ו-208–216, מעותק אחר של אותו כרך (צילום) · `thlv/` (תהלים) · `dhyv/` (דברי הימים) — מקראות גדולות ויניציאה רפ״ד–ו: השלמה לעמודים שחסרים בסריקה.

שמות התיקיות: התיקייה הראשית — קוד הספר, 2–4 אותיות לטיניות משמו העברי, ובספר רב־כרכים הקוד ומספר הכרך; השלמה מדפוס אחר — תיקייה משלה: קוד התיקייה שהיא משלימה ואות המקור (`g` מקראות גדולות · `v` ויניציאה · `x` עותק אחר של אותו דפוס · `l` וילנא · `t` תר״ס · `s` סריקה כפולה שפוצלה לשני עמודיה המודפסים); שם הקובץ — מספר העמוד בסריקת המקור.
