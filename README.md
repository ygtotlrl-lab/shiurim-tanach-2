# שיעורים — תנ״ך 2

`thx/` — תהלים, עמודים 205 ו-208–216, מעותק אחר של אותו כרך (צילום) · `thv/` (תהלים) · `dhv/` (דברי הימים) — מקראות גדולות ויניציאה רפ״ד–ו: השלמה לעמודים שחסרים בסריקה.
